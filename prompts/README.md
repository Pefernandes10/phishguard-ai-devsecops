# Acervo versionado de prompts

Os seis prompts são **artefatos de apoio ao desenvolvimento, revisão, privacidade e operação**. O modelo funcional do protótipo é **aprendizado de máquina clássico (TF-IDF + regressão logística)**, portanto **não usa prompts durante a inferência**.

## Como utilizar
1. Escolha o prompt pela fase DevSecOps.
2. Compartilhe com a IA somente arquitetura, código sem segredos e amostras fictícias.
3. Registre o que a IA recomendou, sem aceitar resultados como evidência automática.
4. Valide com testes, revisão humana e referências oficiais.

Os arquivos podem ser versionados no GitHub, revisados em pull requests e expandidos conforme a evolução do projeto.
